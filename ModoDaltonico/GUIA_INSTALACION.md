# Modo Daltonico - Guia de Instalacion y Uso

## Instalacion

1. Copie la carpeta `ModoDaltonico/` en el directorio `plugins/` de su instalacion MantisBT.
2. Ingrese a MantisBT como administrador.
3. Vaya a **Administracion > Complementos** (Manage > Plugins).
4. Localice **Modo Daltonico** en la lista de plugins disponibles y haga clic en **Instalar**.
5. El plugin quedara habilitado y aparecera en la lista de plugins instalados.

## Configuracion

- Haga clic en el nombre del plugin **Modo Daltonico** en la seccion de Plugins instalados para acceder a la configuracion global.
- Desde ahi puede:
  - **Activar o desactivar** el plugin para todos los usuarios.
  - **Seleccionar el tipo de contraste por defecto**: Protanopia, Deuteranopia o Tritanopia.

## Uso del Boton Flotante

- Una vez instalado, aparecera un **boton flotante** en la esquina inferior derecha de cada pagina.
- Al hacer clic se activa o desactiva el modo daltonico.
- Cuando esta activo, se muestra un **selector de tipo de daltonismo** para elegir entre:
  - **Protanopia** (no ve el rojo)
  - **Deuteranopia** (no ve el verde)
  - **Tritanopia** (no ve el azul)
- Un **indicador** en la parte superior derecha confirma que el modo esta activo.
- La configuracion se guarda en el navegador (localStorage), por lo que se mantiene entre pestanas y sesiones.

## Compatibilidad

- MantisBT 2.0 o superior
- Google Chrome, Safari y Microsoft Edge (versiones recientes)

# Colorblind Mode - Installation and Usage Guide

## Installation

1. Copy the `ModoDaltonico/` folder into the `plugins/` directory of your MantisBT installation.
2. Log in to MantisBT as an administrator.
3. Go to **Manage > Plugins**.
4. Find **Colorblind Mode** in the list of available plugins and click **Install**.
5. The plugin will be enabled and appear in the installed plugins list.

## Configuration

- Click on the plugin name **Colorblind Mode** in the Installed Plugins section to access global configuration.
- From there you can:
  - **Enable or disable** the plugin for all users.
  - **Select the default contrast type**: Protanopia, Deuteranopia, or Tritanopia.

## Using the Floating Button

- Once installed, a **floating button** appears in the bottom-right corner of every page.
- Click it to toggle colorblind mode on or off.
- When active, a **contrast type selector** lets you choose between:
  - **Protanopia** (cannot see red)
  - **Deuteranopia** (cannot see green)
  - **Tritanopia** (cannot see blue)
- A **badge indicator** at the top right confirms the mode is active.
- Settings are saved in the browser (localStorage), persisting across tabs and sessions.

## Compatibility

- MantisBT 2.0 or higher
- Google Chrome, Safari, and Microsoft Edge (recent versions)
